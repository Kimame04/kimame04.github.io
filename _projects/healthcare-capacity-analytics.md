An exploratory data analytics project investigating public hospital bed capacity, utilization rates, and healthcare system strain patterns.

## Overview &amp; Analysis

The project processes historical hospital occupancy and admission data to surface trends across acute and community healthcare facilities:

- Evaluates baseline bed capacity versus seasonal demand spikes.
- Generates interactive visual breakdowns of bed occupancy rates (BOR) across different healthcare clusters.
- Identifies operational bottlenecks and variations in length-of-stay (LOS) distributions.

## Stack &amp; Tools

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Output:** Static reports and interactive web visual dashboards
